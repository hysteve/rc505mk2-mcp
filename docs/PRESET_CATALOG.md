# Preset Catalog — audit snapshot (2026-09-12)

Generated by `npm run catalog:presets` from a static audit of every bundled rack, bundled FX module, and local user rack against the current `PARAM_MAP` and transforms. **No preset in this catalog has been verified on hardware.** Every row starts at `untested`.

Issue kinds:

- **unknown-param** — name not in `PARAM_MAP` for that effect; the generator skips it (device keeps the template default).
- **unrecognized-value** — value not accepted by the transform; falls back to a numeric parse (usually `0`).
- **enum-index** — a plain number given for an enum param (e.g. `LOW CUT: 20`); used as the enum index, not as Hz.
- **out-of-range** — numeric value outside the transform range; written at the clamp boundary.
- **unsupported-note-value** — tempo-synced RATE value; encoding pending device verification.
- **unknown-effect** — effect name (or fxModuleId) not resolvable; the whole slot is skipped.
